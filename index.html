Timing & synchronization

Each row is one synchronized run. Every site's page gets "100" typed at the same instant ("typed"). Each waits for its quote to settle, then all sites read the value that gets compared at the same instant ("values read"). The spreads show how far apart those moments were across sites. Times are UTC.

How this was measured

  • Each site was opened in its own fresh Playwright Chromium browser, with no shared cookies and no wallet. Nothing was connected, signed or swapped.
  • For each route, all six sites load with the route already selected. The runner then types 100 into every page at the same moment. Once every site's quote has settled, all of them read the value that gets compared at the same moment (a second barrier). The timing table above shows how close each run was.
  • Gap in bps = (Bridg's listed quote − venue's own quote) ÷ 100 × 10,000. Negative means Bridg shows less. "Excluding Bridg fee" adds Bridg's own platform fee back, so the gap reflects only the venue's price.
  • USDC contracts: Solana EPjF…Dt1v, Ethereum 0xA0b8…eB48, Base 0x8335…2913, BSC 0x8AC7…580d. BSC's is Binance-Peg USDC, which has 18 decimals and is bridged, not native Circle USDC.
